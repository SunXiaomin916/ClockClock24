# 3.0.0 发布验证

验证日期：2026-10-11。Windows 11 10.0.26300，Electron 44.7.0，Edge 155，Playwright 1.62.1。

## 已完成

- `npm test`：**39 项通过**。包括四个位置分别显示 0–9、三档模式全天 1,440 分钟精确归位、动画打断、配置、材质，以及启动项路径引号、Mac plist 转义／移除和开发模式保护。
- 浏览器回归：**23 项通过**。午夜／整点、12/24 小时、全部材质与编舞、暂停恢复、静止停止绘制、4K／高 DPI／窄屏、离线 file 入口及原生属性回调。无页面运行错误、无外部请求。
- 已打包 Windows EXE：**11 项检查通过**。独立应用启动、窗口隔离、原生 WorkerW 父窗口确认、设置同步、真实用户启动项开启／移除、暂停恢复、壁纸开关、关闭设置仍运行、模拟睡眠恢复、快速连续切换，以及 `--autostart` 启动仅进入壁纸／托盘并保留配置。
- Windows 实际桌面窗口覆盖 2560×1440 逻辑像素，150% 缩放下渲染 3840×2160。检查设置窗口与壁纸截图。测试结束已退出应用并删除测试启动项，默认开机启动保持关闭。
- Wallpaper Engine（文件版本 2.8.0.42）：通过独立窗口加载正式包的 `project.json`，观察完整 24 钟面、当前时间和分钟编舞，网页设置图标正确隐藏。测试后关闭此预览，不替换用户原壁纸。
- 发布 ZIP 写出后逐成员读取，检查 CRC 和 SHA-256，并保存文件清单和压缩包校验和。

## macOS 交付状态

Apple Silicon 与 Intel 分包，内含 `.app`、本地安装脚本、签名授权文件与使用说明。构建保存 Framework 符号链接、Mach-O 执行权限和脚本执行权限；启动开关的 LaunchAgent 文件生成、路径转义、关闭移除通过核心测试。

**没有在 Mac 真机启动，也没有 Developer ID 签名／Apple 公证。** 本地安装脚本使用系统 codesign 生成 ad-hoc 签名。菜单栏、桌面层、Spaces、真实登录启动与休眠恢复仍需 Mac 实测；不能把结构和单元测试当作这些系统行为的验证。

## 未验证范围

- 真正注销／重新登录或重启：Windows 已验证系统登记、移除和登录参数启动，未主动注销用户。
- 原生 Wallpaper Engine 全部属性逐项热切换、屏保组件安装和整夜运行；相关回调只在浏览器自动测试中覆盖。
- Windows 10、Windows ARM、更多系统版本、混合 DPI 多显示器；桌面版目前仅覆盖主显示器。
- 高刷新率档位的真实显示性能及新桌面运行时的长时间 CPU／GPU 采样。
