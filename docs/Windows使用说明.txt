ClockClock 24 3.0.0 — Windows 桌面版
===================================
适用：Windows 10 / 11，64 位 x64（Intel / AMD）。完全离线，不需要 Node.js。

1. 完整解压到固定目录，例如 D:\Apps\ClockClock24。不要只取出 EXE。
2. 双击 ClockClock24.exe。时钟显示在主显示器桌面图标后方，设置窗口同时打开。
3. 关闭设置窗口后，壁纸继续运行。双击任务栏通知区域的时钟图标可再次打开设置。
4. 从托盘菜单选择“退出 ClockClock 24”完全退出，原来的桌面壁纸重新露出。

开机启动（默认关闭）
设置 → 桌面应用 → 开机启动；托盘右键菜单也提供相同开关。
开启后，在当前用户下次登录 Windows 时启动到托盘，不弹设置窗口。
关闭开关会移除此应用的启动项，不需要管理员权限。
如果任务管理器禁用了此项，界面会显示实际状态。
移动程序目录、升级或删除前，先关闭旧版开机启动；在新位置重新开启。
本应用不会开启 Wallpaper Engine 的开机启动。

日常设置
14 种材质、Quiet / Medium / Active、12 组编舞、12/24 小时、显示尺寸、漂移。
帧率有 30 / 60 / 120 / 180 / 240 / 360，首次默认 60；实际受屏幕和设备限制。
设置窗口：C 设置，D 编舞，F 全屏，Esc 关闭设置。
桌面层不接收鼠标点击，以便照常使用桌面图标；请通过托盘打开设置。
“暂停动画”暂停桌面计时/动画，恢复后同步当前时间。
关闭“桌面壁纸”只保留时钟预览窗口，可按 F 全屏展示。
目前桌面层只覆盖主显示器；主显示器与分辨率改变时自动重建。

保存、升级和卸载
外观保存在 %APPDATA%\ClockClock 24\desktop-settings.json（实际目录以系统配置为准）。
同一应用只运行一份；再次启动会打开设置窗口。
升级：关闭开机启动 → 退出旧版 → 用新版完整目录替换 → 运行 → 按需开启开机启动。
卸载：关闭开机启动 → 从托盘退出 → 删除程序目录。用户设置可单独保留或删除。

常见问题
本应用没有商业代码签名，Windows 可能显示发布者未知。仅运行你确认来源的压缩包。
桌面挂载失败时，设置会显示提示；从托盘“重新挂载桌面”重试，也可使用时钟窗口。
Windows 桌面层不是稳定公开接口，系统更新、远程桌面或其他壁纸软件可能影响它。
不要同时让本应用和 Wallpaper Engine 控制同一桌面；使用后者时请先退出本应用。
正式 Wallpaper Engine 包不依赖本桌面应用，位于单独发布包中。
独立桌面版不是 Windows .scr 屏保。系统屏保请用 Wallpaper Engine 的屏保功能。

这是参考 Humans since 1982 视觉语言的独立实现，非官方产品。
静止时不持续绘制；OLED 漂移不能保证防烧屏，长期闲置建议熄屏。
