# ClockClock 24 · Kinetic Desktop

24 个钟面、48 根独立指针组成的离线动态壁纸。3 行 × 8 列排列，每 6 个钟面构成一位数字，显示本机 **HH:mm**（四位数字，不显示冒号）。以 Humans since 1982 的装置为视觉参考，代码和编舞为独立实现，不包含原作固件或专有运动序列。

## 直接运行

双击 `index.html` 即可预览，无需 Node.js、联网或安装依赖。必须保留相邻的 `js/`、`css/` 目录。

- **C** 打开/关闭设置，**D** 播放完整编舞，**F** 浏览器全屏，**Esc** 或点击设置面板外的空白处关闭设置。
- 设置图标在鼠标静止 10 秒后淡出，再次移动鼠标即显示；设置面板打开时保持可见，关闭后重新计时。键盘聚焦时保留可见反馈，触摸或键盘操作也会唤出图标。
- 浏览器设置保存在 `localStorage`，兼容旧版 `cc24_settings`。
- 设置采用瓷白面板、双钟面标识与凹陷控件，分为外观、运动和显示；开发预览默认折叠，点击展开后可模拟时间、检查数字。小窗口中面板可滚动，关闭时恢复干净的时钟画面。
- Wallpaper Engine 原生属性优先，浏览器历史设置不会覆盖壁纸属性。宿主加载后隐藏网页设置按钮，避免桌面误触。

## Wallpaper Engine 导入

1. Steam → Wallpaper Engine → 管理 → 浏览本地文件。
2. 打开 `projects/myprojects`，不存在则创建。
3. 将当前完整文件夹复制进去，如 `projects/myprojects/ClockClock24_WallpaperEngine/`。
4. 确保 `project.json` 与 `index.html` 位于项目根目录。刷新或重新打开 Wallpaper Engine，选择本地项目并应用。
5. 在原生属性面板中调整主题、模式、编舞曲目、尺寸、帧率、12/24 小时制和漂移。

也可通过编辑器拖入 `index.html` 创建 Web 壁纸，但编辑器可能重建配置。应保留本工程的 `project.json` 属性定义，并复制全部 `js/`、`css/` 文件。

本机独立窗口预览命令如下，其他电脑需替换安装路径与项目路径：

```powershell
& 'F:\SteamLibrary\steamapps\common\wallpaper_engine\wallpaper64.exe' `
  -control openWallpaper `
  -file 'C:\Projects\ClockClock24\project.json' `
  -playInWindow 'ClockClock 24 Preview' -width 1280 -height 720
```

关闭该窗口即可结束预览。此方式无需改变桌面壁纸。

## 屏幕保护程序

在 Wallpaper Engine 的屏保配置中安装其屏保组件，再在 Windows“屏幕保护程序设置”中选择 Wallpaper Engine。可使用当前壁纸，也可单独指定本项目。屏保入口由宿主提供，本工程没有独立 `.scr`。参见 [官方屏保说明](https://help.wallpaperengine.io/zh/functionality/screensaver.html)。

默认在分钟变化时编舞，其他时间静态显示。“播放一次编舞”完整预览所选曲目的 Active 版本；选择自动轮播时，每次播放下一组。系统开启“减少动态效果”时实际运动使用 Quiet。

2.3.1 增加 120、180、240、360 FPS 档位，并移除浏览器预览的内部 60 FPS 限制和宿主回调的 240 FPS 截断。选择的是动画帧率上限，实际帧率还取决于浏览器／宿主的 `requestAnimationFrame` 调度、显示器刷新率与设备性能；选择 360 不代表低刷新率屏幕能显示 360 帧。动画按时间推进，高帧率不会加快编舞。Wallpaper Engine 全局限制仍然优先，例如本项目选 360、全局选 60 时，上限为 60。

### 2.3 多阶段编舞

从原有六组单一队形扩展为十二组，每组都有展开、变化和重新显示时间的过程。按 **C → 编舞曲目 → 播放一次编舞** 逐组查看；关闭设置后按 **D** 也可播放。选择自动轮播时，Active 使用全部十二组，Medium 轮播行进波浪、同步钟摆、逐行瀑布、镜像对开和交织流线。指定一组时，Medium 使用该曲目的简化版本，Quiet 始终只走最短路径报时。

| 曲目 | 运动结构 |
| --- | --- |
| 行进波浪 | 双针排成平行直线 → 旋转逐列传递 → 反向回波 |
| 同步钟摆 | 全体向左摆 → 向右摆 → 再回摆 |
| 同心螺旋 | 切向环阵 → 按外圈至内圈接力旋转 → 收拢 |
| 花瓣开合 | 指向中心的窄夹角 → 双针张开 → 闭合 |
| 逐行瀑布 | 水平列阵 → 由上向下翻转 → 反向涌起 |
| 棋盘翻转 | 横竖相间 → 相邻钟面反向翻面 → 交换回来 |
| 镜像对开 | 左右向外展开 → 镜面对转 → 合拢 |
| 四组风车 | 四个局部轮心 → 同向旋转 → 展平 |
| 双针逆流 | 双针相迎 → 顺逆时针穿行 → 交汇 |
| 交织流线 | 正弦斜纹 → 相位翻转 → 流线回转 |
| 交错剪刀 | 棋盘错峰张开 → 剪刀合拢 → 换向张开 |
| 散开重聚 | 分散角度 → 不同方向旋转 → 整齐竖直列阵 |

阶段采用共同时间轴与错峰启动；平行双针、左右镜像等关系能够在运动中保留。速度和加速度限制、打断时的连续减速、结束时标准角度归位继续有效。运行时没有视频播放，也没有新增依赖。

参考核对：截至本次查看，[官方 CC24 页面](https://www.humanssince1982.com/products/clockclock-24-white)说明 Active 有 10 组、Medium 有 5 组、Quiet 只报时。该页约 41 秒视频和[白金页面](https://www.humanssince1982.com/products/clockclock-24-white-gold)的展示片段主要是“数字散开—平行双针—逐列波浪—数字重组”。[官网首页](https://www.humanssince1982.com/)约 34 秒的大尺寸装置片段可观察到同心环开合、旋涡和流线变化。首页装置的钟面数量更多，不能直接套用其几何细节。上述十二个名称、轨迹与时长是本工程独立设计，未宣称复刻官方未公开的全部运动序列。

### 2.2 金属反射

银色和金色指针采用固定摄影棚环境光，包含宽柔光、窄条反光、暗部环境和暖色反弹光。指针转动时，微弧针面、倒角法线和拉丝方向随之转动，采样到的反射发生变化，高光会扫过针面。原有 Black Gold 主题也使用此效果；蓝银、绿金和 Decade 的哑光伙伴指针保持各自色彩。

光照模型将简化环境反射与各向异性 GGX 高光结合，保留金／银各自的反射颜色；相关材质原理参见 [Filament 光照文档](https://google.github.io/filament/main/filament.html)。这是一种离线可运行的 2.5D 近似，不是光线追踪，也不读取用户桌面或摄像头环境。

每种金属预计算 128 个角度的材质图集，动画帧中对相邻角度连续混合，跨 360° 时首尾相接。投影方向固定在屏幕空间。静止的指针与固定光源之间没有相对变化，因此静止时不添加闪烁动画、不持续重绘。预览可选择“白银”“白金”或“黑金”，按 **D** 播放编舞来观察变化。

## 开发预览

Node.js 18 或更新版本，在当前目录运行：

```powershell
npm start
```

打开 [开发预览](http://127.0.0.1:8765/?dev=1)。端口冲突时先设置 `$env:PORT=8766`。服务只监听本机回环地址。

`?dev=1` 启用模拟时间、数字检查与诊断。底部状态信息只在设置面板打开时显示，关闭面板后自动隐藏。普通壁纸入口不暴露修改时间接口：

```text
http://127.0.0.1:8765/?dev=1&time=23:59:55
http://127.0.0.1:8765/?dev=1&digits=8888
```

模拟时间仅在内存中，不修改系统时钟、不保存到壁纸属性。保留旧版控制台入口，并增加诊断接口：

```javascript
CC24.getSettings();
CC24.getTime();                        // 正在过渡到的四位时间
CC24.getAngles();                      // 48 个角度，北=0，顺时针
CC24.setSetting('theme', 'porcelain');
CC24.showDemo();
CC24.getDiagnostics();                 // 帧数、画布尺寸、存储估计、暂停状态
// 仅 ?dev=1 有效
CC24.debug.setTime('23:59:59');         // 动画过渡
CC24.debug.setTime('23:59:59', false);  // 立即定位
CC24.debug.setDigits('0123');
CC24.debug.live();
```

浏览器里可模拟宿主回调：

```javascript
wallpaperPropertyListener.applyUserProperties({theme: {value: 'oled'}});
wallpaperPropertyListener.applyGeneralProperties({fps: 30});
wallpaperPropertyListener.setPaused(true);
wallpaperPropertyListener.setPaused(false);
```

### 性能采样

以下为 2.0 阶段（配色扩展前）的历史采样：本机无头 Edge，3840×2160、86% 尺寸、60 FPS，采样约 4 秒 Active 编舞：

| 指标 | 原版 | 2.0 版 |
| --- | ---: | ---: |
| 动画期间创建径向渐变 | 5,900 次 | 0 次 |
| 主线程 TaskDuration 增量 | 0.147 秒 | 0.127 秒 |
| ScriptDuration 增量 | 0.063 秒 | 0.043 秒 |
| 指针绘制调用 P95 | — | 约 0.2 ms |

这是单次采样，两个版本编舞工作负载不同，不能推算整机 CPU/GPU 降幅或其他机器帧率。绘制调用耗时不含 GPU 异步执行、桌面合成。

4K 标准尺寸 DPR=1，两层画布后备存储约 **36.96 MiB**；高 DPI 自动限制至约 **45.75 MiB**，不含浏览器、纹理副本和合成器内存。静止时每 5 秒以内轻量核对时间，不绘制；开启漂移约每 10 秒更新位置。分钟边界自动同步，系统时间突变最多约 5 秒后同步，收到恢复事件立即同步。

2.2 使用有界的金／银角度图集缓存，仅在首次使用或渲染分辨率变化时计算；动画帧不创建渐变、不逐像素计算光照。两款石纹主题各增加约 **1.98 MiB** 的纹理画布。`CC24.getDiagnostics().materialMiB` 单独报告当前所有材质画布存储估计，不包含在 `backingMiB` 中。上述 2.0 主线程耗时不能作为新版的重新测量结果。

2.2 新采样：无头 Edge 155，3840×2160、86%、60 FPS，Sunset Dune 同时使用金、银和石纹，约 4 秒实际时间绘制 **241 帧**；Canvas 绘制调用 P95 为 **0.3 ms**，材质画布约 **6.30 MiB**，两层主画布仍为 **36.96 MiB**。归位后 2.1 秒增加 **0 帧**、无待处理 RAF。另在指针几何位置保持不变的像素测试中，0° 和 45° 的反射明显不同，0° 和 360° 完全一致。这是本机一次采样，不代表 GPU 完成时间或 Wallpaper Engine 实际帧率保证。

## 从旧版改进了什么

保留原有布局模型、五种材质、三档模式、属性键、设置面板、快捷键与控制台入口。将单文件拆为普通脚本，避免 ES Modules 在本地文件的加载限制，无构建工具或运行时框架。

纠正 8 的中排右钟面方向，保留 3/6 等字形的半段笔画。双针单元无法在一个钟心同时画三个方向，因此它不是七段数码管。双针改为等长等宽，缩小钟面间距、增加数字分组间距，面板保留 9:4 比例；减弱发光，改为细微投影与凹陷明暗。

五次轨迹起止速度和加速度为零，打断时连续减速再衔接新轨迹，终点直接赋值为标准角度。速度和加速度峰值限制适用于静止到静止段；短减速桥接优先保证连续性，不承诺与主体段相同的峰值限制。

背景由 CSS 绘制，静态面板缓存到独立 Canvas，动画只更新变化的钟面矩形。修复旧版混用 `Date.now()` / `performance.now()` 导致的漂移重绘；静止停止 RAF，暂停与不可见停止计时；增加设置校验、恢复同步与高 DPI 像素预算。
